# Akash Verma

Personal portfolio of Akash Verma, a full stack developer and Information Technology student at Asansol Engineering College.

A quiet life, meaningful work, and the freedom to choose both.

## About the site

A single page, black and white, set entirely in Poppins. It has sections for About, Stack, Projects, Journey and Contact.

It is built with plain HTML, CSS and JavaScript. There is no framework, no build step and no animation library. The motion is written in CSS, with a small IntersectionObserver for scroll reveals, and it switches off for anyone who prefers reduced motion.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The page and all of its content |
| `styles.css` | Layout, typography and animation |
| `main.js` | Section highlighting, the phone menu and scroll reveals |
| `assets/hero.jpg` | The hero portrait |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | Tab and home screen icons |

## Run it locally

Open `index.html` in a browser, or serve the folder:

```
python -m http.server
```

Then visit http://localhost:8000.

## Add a project

In `index.html`, copy one `<article class="row project">` block in the Projects section, then change the name, link, status, description and tags.

## Deploy

Hosted on Vercel as a static site. Framework preset is Other, with no build command and the project root as the output directory. Every push to `main` deploys automatically.
